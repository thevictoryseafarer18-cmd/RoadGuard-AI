Detection mode

Live uses the server's OpenCV camera; demo uses simulated detections.

Location

Reset demonstration data

Restore the original sample records. Real citizen and camera records are kept.

How priority works

40% severity + 20% traffic + 15% road importance + 10% nearby sensitive locations + 10% citizen reports + 5% damage age. Demo values and default inputs are illustrative. Heuristic detections can be false positives.
